# Machine Learning Internship Tasks - InternSpark

Welcome to my unified portfolio repository containing all machine learning project tasks completed as part of the InternSpark internship.

##  Projects Included

* **Task 1: Iris Flower Classification**
  * **Objective:** Perform Exploratory Data Analysis (EDA) and build classification models to categorize Iris flower species: 
  * **Techniques Used:** Data preprocessing, standard scaling, label encoding, Support Vector Machines (SVC), and Logistic Regression.
  * **Notebook:** [iris-flower-classification-analysis TASK 1 Machine Learning.ipynb]

* **Task 2: House Price Prediction**
  * **Objective:** Analyze housing dataset features, handle null values, and predict housing prices using advanced regression techniques.
  * **Techniques Used:** In-depth EDA, handling skewness, outlier detection via box/Q-Q plots, cross-validation, and GridSearchCV.
  * **Notebook:** [house-price-prediction TAsk 2 Machine Learning.ipynb]

* **Task 3: Titanic Survival Prediction**
  * **Objective:** Predict passenger survival on the Titanic using demographic and travel data.
  * **Techniques Used:** Data visualization, missing value imputation, feature mapping, and training multiple classifiers (Logistic Regression, Decision Trees, Random Forest, SVC, KNN).
  * **Notebook:** [titanic-survival-prediction Task 3 Machine Learning.ipynb](titanic-survival-prediction%20Task%203%20Machine%20Learning.ipynb)
